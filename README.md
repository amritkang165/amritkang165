<details open>
<summary><kbd>&nbsp;🏙️ &nbsp;<b>MERAWARD</b>&nbsp;</kbd></summary>
<br>

Delhi has 289 wards. most people — including the people who *live* there — don't know which one they're in. i built something that fixes that: drop a pin, find your ward, file a complaint by voice or photo, get a bilingual letter drafted by AI, and see which wards the government keeps ignoring ranked on a public dashboard.

built in 2 days at First Commit (WeMakeDevs × AWS). i led the team and built the entire frontend and ward pipeline. ~2ms API response. 254 tests. 100 Lighthouse score.

`Lambda` `Bedrock` `DynamoDB` `SQS` `React 18` `MapLibre` `Python`

→ [repo](https://github.com/amritkang165/meraward)
<br>
</details>

<details open>
<summary><kbd>&nbsp;🧬 &nbsp;<b>ReGit</b>&nbsp;</kbd></summary>
<br>

researchers version-control their work with git. git was built for line-oriented text. research is not line-oriented text. so i built a VCS that actually understands what research artifacts are — PDFs, LLM chats, codebases, datasets. content-addressed commits, semantic diffs, 3-way prose merge, real-time CRDT collaborative editing, hybrid BM25 + vector retrieval. fully offline, single process.

120 tests. top 6 at Gradient Rush Hackathon.

`Python` `FastAPI` `React` `pycrdt` `yjs`

→ [repo](https://github.com/amritkang165/ReGit)
<br>
</details>

---

<details open>
<summary><kbd>&nbsp;📅 &nbsp;<b>Placement Week Scheduler</b>&nbsp;</kbd></summary>
<br>

campus placement week is chaos. 800 students, 35 companies, 20 rooms, 1123 shortlists, and if one interview overruns, the whole thing collapses. i built a CP-SAT constraint solver that reaches 99.5% interview coverage with zero clashes and 90% room utilization — and a disruption-aware replanner that re-solves only the affected slice when something breaks, touching just 1.4% of appointments.

45 tests.

`Python` `OR-Tools` `FastAPI` `React`

→ [repo](https://github.com/amritkang165/placement-week-scheduler)
<br>
</details>

`Swift 6` `SwiftUI` `SwiftData` `Vision`

→ [repo](https://github.com/amritkang165/Pocki)
